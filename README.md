One original line roasting the app that demands a five-star rating before it has even let you in — the loading screen that asks for a verdict on a product you have not used yet.

> This app asked me to rate it five stars before it even opened — I've had job interviews that asked less of me than this loading screen.

Run `python3 main.py` to write the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).
